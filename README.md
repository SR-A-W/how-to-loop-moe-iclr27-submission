# How to Loop MoE — ICLR 2027 submission (anonymous)

Anonymized code and artifacts accompanying the ICLR 2027 submission
*"How to Loop MoE"* will be released in this repository after the review period.

At the moment this repository is a placeholder. It will contain:

- model and training code for the looped mixture-of-experts variants studied in the paper;
- evaluation and probing scripts (downstream tasks, router statistics, expert masking);
- configuration files for the reported runs.

No author-identifying information is included in this repository.
